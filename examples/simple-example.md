# Simple two-stage confirmation

**User**

```text
Use $confirm-with-pseudocode to compare PostgreSQL and SQLite for an offline
desktop app. Prioritize simple deployment and recommend one for a three-person
team.
```

**Assistant**

```text
COMPARE PostgreSQL and SQLite
    FOR an offline desktop application
    PRIORITIZING simple deployment

RECOMMEND an option
    FOR a three-person team
```

The assistant asks the user to confirm or correct this interpretation and
stops.

**User**

```text
Confirmed.
```

**Assistant**

```text
GATHER information needed to compare both databases

COMPARE PostgreSQL and SQLite
    FOR the confirmed application context
    PRIORITIZING simple deployment

ASSESS relevant tradeoffs

FORM the requested recommendation
```

The assistant asks for plan confirmation and stops again. Only the next clear
confirmation authorizes the substantive comparison.
